# HU-Mania Workspace

This repository contains multiple homework assignments (HW3, HW4, HW5) for a C++ course, each focused on SDL2-based graphical programming and game development. Each assignment is self-contained in its own folder and includes source code, assets, and build instructions.

## Structure
- `HW3/` — Homework 3: Basic SDL2 game setup and rendering.
- `HW4/` — Homework 4: Adds new entities and more advanced object-oriented design.
- `HW5/` — Homework 5: Further abstraction, inheritance, and additional features.

Each `HWx/HUMania/` folder contains:
- C++ source and header files
- Game assets (images, audio)
- Compilation instructions

## General Build Instructions
1. Open the relevant `HWx/HUMania/` folder in VS Code.
2. Use the terminal to compile all `.cpp` files. (See each HW's README for details.)
3. Run the resulting executable to play the game.
